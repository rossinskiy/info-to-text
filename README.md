# info-to-text

A CLI that converts item SNBT (as copied by the [InfoCopy](https://github.com/rossinskiy/info-copy-mod) mod) into legacy `&` color codes.

## Usage
Copy item data to your clipboard, then:
```bash
python pull.py
```
It reads the clipboard and asks whether you want the lore, the name, or both.

## Requirements
- Python 3
